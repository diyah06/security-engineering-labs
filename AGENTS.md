# Learning contract

- Teach before non-trivial changes. Work in small checkpoints.
- Explain commands and expected output before execution. Let the learner run experiments unless explicitly asked to run them.
- Use only synthetic infrastructure and data; never add credentials, tokens, kubeconfigs, private keys, or employer material.
- Keep every lab README's fundamentals, architecture, threat model, experiment, expected behavior, observed behavior, security implications, and lessons learned sections.
- Never invent observed output or claim an unrun lab is reproduced.
- Preserve insecure and hardened examples separately; explain their diff.
- Cite primary sources for news and version-dependent claims. Distinguish a news claim from what the experiment proves.
- Publish only accurate status and reviewed, sanitized evidence.
